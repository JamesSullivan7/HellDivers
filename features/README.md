# FEATURE MODULES

Self-contained verticals. Each feature owns its screens, components, and hooks.

- `combat/` — CombatScreen, Battlefield, PlayerHand, Timeline, ActionBar, HUD, overlays
- `armory/` — Warbonds, Ship Modules, Cosmetics
- `map/` — Galactic War map, planet nodes, sector view, liberation bars
- `squad/` — Squad screen, chat, presence indicators
